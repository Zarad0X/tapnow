# Tapnow 软件工程项目演示脚本

## 30 秒开场

Tapnow 是一个面向 AI 图像和视频创作的可视化工作流编排工具。它把故事文本、图片、视频、提示词、生成模型、历史素材和本地保存串成节点图，让创作者可以用拖拽和连线组织复杂的 AI 创作流程。

## 1 分钟：系统界面和工程结构

先展示画布。右键画布可以添加不同节点：小说输入、视频输入、视频拆解、智能分镜表、AI 绘图、AI 视频、预览窗口和本地保存。

强调工程点：

- 前端是 Vite + React。
- 节点状态、连线、历史记录、角色库都能保存到项目 JSON。
- 生成接口被封装为多模型适配层。
- 本地连接器负责缓存、保存和删除素材。

## 1 分钟：加载预置项目

点击左侧加载项目按钮，导入：

```text
demo/tapnow-demo-project.json
```

导入后说明这不是静态截图，而是一个真实 Tapnow 项目：节点、连线、历史素材、聊天记录和角色库都已恢复。

## 1 分钟：故事到资产工作流

从左到右讲：

1. 小说输入节点：保存故事设定。
2. 提取角色和场景节点：把故事拆出“阿青”和“雨夜未来集市”。
3. 角色描述和场景描述节点：分别沉淀可复用的视觉设定。
4. AI 绘图节点：用角色和场景设定生成关键视觉图。
5. 预览节点：集中展示生成结果。

可现场操作：

- 拖动节点。
- 点开历史面板。
- 右键历史图片发送到预览或画布。

## 1 分钟：视频拆解到分镜

展示视频输入节点里已经有关键帧。视频拆解节点里已经预置了两段分析结果，包括：

- 画面描述
- Midjourney 英文提示词
- 即梦中文提示词
- 风格、镜头、色彩标签

然后展示智能分镜表：每个镜头有图片、描述、prompt、运镜、模型、比例和时长。现场可以改一个镜头的 prompt，说明 Tapnow 支持人工修订和 AI 生成结合。

## 30 秒：生成与保存

展示 AI 视频节点和本地保存节点。说明真实演示时不现场等待长视频生成，避免网络、排队、Key 或 CORS 问题；生成结果已经保存在历史记录中，可以被重新发送到画布、预览和本地保存。

## 30 秒收尾

Tapnow 的价值不是单个模型调用，而是把创作流程工程化：输入、分析、生成、预览、复用和保存都在同一个可视化项目里管理。软件工程部分体现为模块化 React 组件、服务层封装、项目持久化、本地连接器和 smoke/build/browser 自动检查。

## 现场兜底

如果 API 不通，只演示预置项目和本地交互：

- 加载项目
- 拖动节点
- 查看历史
- 发送素材到画布/预览
- 编辑分镜 prompt
- 保存项目 JSON

这条路线不依赖外部服务，最稳。
